# Cadre du musée

Le cadre est servi depuis `public/images/museum/cadre.png` afin que le
navigateur puisse le charger depuis le même domaine et analyser son ouverture.
Il peut être remplacé sans modifier le code : fournissez un PNG avec un centre
transparent. Le ratio largeur/hauteur est libre ; un fichier de 600 × 800 px est
recommandé. L'ouverture est détectée automatiquement à partir de l'alpha.
